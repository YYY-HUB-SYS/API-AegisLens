01

功能特性

围绕密钥全生命周期的十项核心能力：录入、验证、补全、生成、监控。

加密存储

密钥以 AES-256-GCM 字段级加密落盘，其余字段明文存储；主密钥 master.key 与数据文件同目录，拿到该目录即可解密，请按明文密钥对待。

双存储后端

Node ≥ 22 时走 SQLite（node:sqlite），18–21 自动改用 JSON 文件，无需额外安装任何数据库；两种后端之间不自动迁移数据。

多兼容端点

同一 Key 可配最多 6 个 Base URL（OpenAI / Anthropic / 自定义兼容模式）。如 DeepSeek 可同时登记 api.deepseek.com 与其 Anthropic 端点。

连通性测试

优先调用平台模型列表接口验证密钥可用性；无列表接口的端点（如火山方舟 Agent Plan）自动回退对话接口鉴权探测。

模型目录

自动拉取模型列表；上下文长度与最大输出经四级兜底补全：平台接口 → 内置元数据库 → 联网检索（OpenRouter / models.dev）→ 手动补充。

配置生成

按目标工具套用模板并自动带入模型参数：Dify / n8n 取 OpenAI 兼容端点，Claude Code 取 Anthropic 兼容端点（生成 ANTHROPIC_BASE_URL / ANTHROPIC_AUTH_TOKEN），另提供 .env 模板。

余额监控

按 Base URL 域名自动匹配官方余额接口（DeepSeek / Moonshot / Kimi / 智谱），自定义平台指向官方域名同样可查；多端点依次回退，一键刷新全部密钥。

有效期管理

登记密钥注册时间（支持一键填入「现在」），临期（30 天内）与过期状态自动判定，看板醒目标记。

代理自动检测

境外中转站等直连不可达的端点，自动走系统 / 环境变量代理（CONNECT 隧道）；请求带编程工具 User-Agent，以通过中转站客户端检测。

零依赖

纯 Node.js 标准库实现，git clone 后无需 npm install 即可运行；便于审计、内网部署与长期维护。

02

安全设计

密钥是敏感资产，安全边界从存储到网络逐层收紧。

字段级加密落盘

只有密钥字段以 AES-256-GCM 加密后写入存储文件，其余字段为明文；主密钥与数据同目录，整个数据目录等同明文密钥。导出的 JSON 默认连 key 字段都不带，要含明文得在导出时显式勾「包含明文密钥（风险自担）」，勾上才逐条向保险库取用——那一份文件就是明文，风险自担不是一句客气话。

仅本地监听

默认只绑定 127.0.0.1，不暴露到局域网与公网；界面与接口同源，数据全程不出本机。想让别的设备访问，得显式设 AKM_BIND——而没设解锁口令时这条会被直接拒绝启动（不是警告），因为局域网里任何人都能对着界面点「显示」。放开了就不再是「数据不出本机」，边界改成看你局域网有多大，见部署指南。

同源写校验

所有写接口校验请求同源性，拒绝跨域写入；但应用没有登录鉴权，本机进程可直接读到解密后的密钥，请勿反向代理暴露。外发请求仅用于连通性测试、模型拉取与余额查询，密钥只发往你自己填写的端点。

说明：仓库中所有 sk- 开头的样例密钥均为演示用假密钥，不含任何真实凭据。

04

使用流程

四步完成从录入到投放：新增密钥 → 测试连通 → 拉取模型 → 生成配置。

Step 1

新增密钥

选择内置平台或自定义，填入 API Key，地址与默认模型自动填充；可为单个 Key 配置多个兼容端点与特殊认证说明，登记注册时间。

Step 2

测试连通

一键验证密钥可用性；无模型列表接口的端点自动回退对话接口鉴权探测，结果即时反馈到看板。

Step 3

拉取模型

自动拉取模型目录，上下文与最大输出参数不足时联网补全，仍缺失可手动补充；参数支持一键复制精确数值。

Step 4

生成配置

按 Dify / n8n / Claude Code / .env 模板生成配置片段，自动带入模型参数并按目标工具选择正确端点，整段复制即用。

快速开始

环境要求：Node.js ≥ 18。无需安装任何依赖，克隆即用。

1克隆并启动

bash 
$ git clone https://github.com/YYY-HUB-SYS/API-AegisLens.git$ cd API-AegisLens/app$ npm start

Windows 用户也可以直接双击 app\start.bat 启动，无需命令行。

2打开界面

浏览器访问 http://127.0.0.1:37700 即可使用。首次运行会在 ~/.api-aegislens 创建数据目录并生成主密钥。

3运行测试

bash 
$ cd app$ npm test100+ 项测试覆盖：加密 / 双存储后端 / API 集成 /平台适配器 / 参数补全 / 代理 / 启动脚本

环境变量

变量默认值说明
AKM_PORT 37700 服务监听端口
AKM_BIND 127.0.0.1 监听地址。默认只有本机能连；填局域网 IP 或 0.0.0.0 才对其他设备可达，而没设解锁口令时这样设会直接启动失败——那条门槛是故意不留缝的
AKM_DATA_DIR ~/.api-aegislens 数据目录（加密存储与主密钥）
AKM_PASSPHRASE 未设 启动时自动解锁。只在没得选的时候用（计划任务 / systemd）：它等于把口令明文写进配置里，常规路径还是界面上的解锁门
AKM_IDLE_LOCK_MINUTES 5 解锁后无操作多久自动上锁（分钟）。真正读写数据的请求会续期，页面轮询那几个只读接口不会——否则标签页一直开着就永远不锁
AKM_SCHEDULE_ENABLED 关 开启定时刷新余额。默认关：开了之后服务每次活着都会周期性朝全部厂商发真实请求，这件事得用户自己点
AKM_SCHEDULE_INTERVAL_MINUTES 60 定时刷新间隔（分钟，1 分钟 ~ 7 天，超出夹取）。界面里没有这项开关，运行时接口 POST /api/schedule 改了不持久，重启回到这里的值
AKM_PROXY 自动检测 外发请求代理。默认依次检测 HTTPS_PROXY / HTTP_PROXY 环境变量与 Windows 系统代理；设为 off 强制直连，或设为 http://127.0.0.1:7897 显式指定
